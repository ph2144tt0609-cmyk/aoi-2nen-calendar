# 葵小 学年別 行事カレンダー（令和8年度 後期）

保護者に配る購読用カレンダー。ページで学年（1〜6年）を選んで、iPhone／Googleカレンダーに追加する。
公開URL: https://ph2144tt0609-cmyk.github.io/aoi-2nen-calendar/ （学年を直接開くなら `?g=3` など）

- 正本は `build.py` の `EVENTS` だけ（1行に対象学年を持つ）。直したら `py -X utf8 build.py` → commit → push（main直配信）
- 出力：`grade1.ics`〜`grade6.ics`／`aoi-2nen.ics`（初版で配ったURL。中身は2年と同じ）／`index.html`
- 載せるのは学校の配付物にある行事だけ。家族の予定・子どもの名前は入れない
- 委員会・代表委員会は5・6年、クラブは4〜6年として扱う（表に学年の記載がないため）
- リポジトリ名は初版（2年だけ）の名残。名前を変えると公開URLが変わり、配ったリンクが切れるので変えない
